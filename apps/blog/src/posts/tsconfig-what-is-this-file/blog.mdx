## What is a module?

Before we dive in, let's get some things straight.

People tend to be scared when they hear the word "module",
because of the complexity of the module **system** in JavaScript.
But a module itself is just a _self-contained_ piece of code.
It does not rely on anything outside of it.

<CodeBlock
  files={[
    {
      name: 'add.ts',
      content: 'const add = (a: number, b: number) => a + b;',
    },
    {
      name: 'calculator.ts',
      content: `class Calculator {
    add(a: number, b: number) {
      return a + b;
    }
  }`,
    },
  ]}
></CodeBlock>

But now what if I want to use the `add` function from `add.ts` in `calculator.ts`?
Without a module system, I would have to come up with my own solution, like copy-pasting
the `add` function into `calculator.ts`. But that would become a mess very quickly.
